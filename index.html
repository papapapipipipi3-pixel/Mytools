Moderation Commands

Essential moderation tools to keep your server safe. Requires Administrator permission.

Tkick / /kick
ADMINPREFIX / SLASH

Kick a member from the server with an optional reason. Protected against self and hierarchy actions.

Syntax
Tkick @member [reason]
Tban / /ban
ADMINPREFIX / SLASH

Ban a user from the server by mention or ID, with optional reason and message deletion days.

Syntax
Tban @user [reason] [delete_days]
Tmute / /mute
ADMINPREFIX / SLASH

Timeout / Mute a member for a specified duration in minutes (max 28 days).

Syntax
Tmute @member [minutes] [reason]
Tunmute / /unmute
ADMINPREFIX / SLASH

Remove timeout / unmute a previously muted member.

Syntax
Tunmute @member [reason]
Tunban / /unban
ADMINPREFIX / SLASH

Unban a user from the server using their numeric User ID.

Syntax
Tunban user:123456789012345678 [reason]
Tpurge / /purge
ADMINPREFIX / SLASH

Bulk delete messages in the channel (1 to 500) with confirmation dialog.

Syntax
Tpurge 1-500

Create Commands

Create multiple Discord server resources quickly with batch commands.

OWNERPREFIX / SLASH

Create up to 10 Discord roles at once. Each role receives a random color.

Syntax
Tcreateroles raw:name1, name2

OWNERPREFIX / SLASH

Create up to 10 text channels at once.

Permissions & Access

Understanding permission requirements in My Tools v1.4.2.

SERVER OWNER

Full access to structural commands: create, rename, delete, bulk delete, and raw ID inspection tools.

ADMINISTRATOR

Access to moderation commands (kick, ban, mute, unmute, unban, purge), serverinfo, userinfo, language, and help.
