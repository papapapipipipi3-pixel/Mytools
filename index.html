Create Commands

Create multiple Discord server resources quickly with batch commands.

⌕
Tcreateroles
OWNERPREFIX

Create up to 10 Discord roles at once. Each role receives a random color. Designed for fast server setup.

Syntax
Tcreateroles name1, name2, …
Example
Tcreateroles Admin, Moderator, Member
Tcreatechannel
OWNERPREFIX

Create up to 10 text channels at once.

Syntax
Tcreatechannel name1, name2, …
Example
Tcreatechannel general, chat, media, memes
Tcreatevoice
OWNERPREFIX

Create up to 10 voice channels.

Syntax
Tcreatevoice name1, name2, …
Example
Tcreatevoice General, Gaming, Music
Tcreateforum
OWNERPREFIX

Create up to 10 forum channels.

Syntax
Tcreateforum name1, name2, …
Example
Tcreateforum Support, Suggestions, Discussion
Tcreatecategories
OWNERPREFIX

Create up to 10 categories.

Syntax
Tcreatecategories name1, name2, …
Example
Tcreatecategories INFORMATION, COMMUNITY, STAFF

Rename Commands

Batch rename channels and categories in one go.

Trenamechannel
OWNER

Rename up to 10 channels at once.

Syntax
Trenamechannel old, new; old2, new2
Example
Trenamechannel general, main-chat; memes, media
general→main-chat memes→media
Trenamecategories
OWNER

Rename up to 10 categories at once.

Syntax
Trenamecategories old, new; old2, new2
Example
Trenamecategories COMMUNITY, COMMUNITY CHAT; STAFF, STAFF AREA
COMMUNITY→COMMUNITY CHAT STAFF→STAFF AREA

Delete Commands

Remove server resources with confirmation protection.

Tdeleteroles
OWNER

Delete roles by mention or name.

Syntax
Tdeleteroles @Role / name
Tdeletechannel
OWNER

Delete channels by mention or name.

Syntax
Tdeletechannel #channel / name
Tdeletecategories
OWNER

Delete categories by ID or name.

Syntax
Tdeletecategories name / id
Tdeleteallcategories
OWNER

Delete all categories. This action cannot be undone.

Are you sure?

Tdeleteallchannel
OWNER

Delete all non-category channels. This action cannot be undone.

Are you sure?

Tdeleteallroles
OWNER

Delete all deletable custom roles. This action cannot be undone.

Are you sure?

Tpurge
ADMIN

Bulk delete messages. Range: 1–500. Accurately deletes the exact number requested.

Syntax
Tpurge 1-500

Utility Commands

Inspect and manage server information with clean interactive utilities.

Tlistroles
OWNER

View a clean, paginated list of all server roles.

Tlistchannel
OWNER

View a clean, paginated list of text channels.

Tlistvoice
OWNER

View a clean, paginated list of voice channels.

Tlistforum
OWNER

View a clean, paginated list of forum channels.

Tlistcategories
OWNER

View a clean, paginated list of categories.

Tlistid
OWNER

Interactive menu for browsing raw IDs. Categories: Channels, Voice, Forum, Categories, Roles.

Tserverinfo
ADMIN

Display: Server ID, Owner, Member count, Role count, Channel count, Boost count.

Tuserinfo
ADMIN

Display: Member name, Member ID, Top role, Join date.

Tlanguage
ADMIN

Switch My Tools language per server. Available: English, Indonesian.

Thelp
ADMIN

Interactive help menu with dropdown categories: Bot Information, Permission Category, Prefix Command, Slash Command, Support.

Select a category to view commands and details.

Permissions & Access

Bot Access: Server Owner and Admin. Special bot-developer access is not required for normal server management.

SERVER OWNER

Full access to all management commands. Can use create, rename, delete, and utility features.

ADMIN

Standard administrative access for server setup and bulk operations.
